# AnomalyWall Team Portfolio

Đây là trang web chính thức của **AnomalyWall Team**, được tạo và phát triển bởi **Enriah**. Trang web đóng vai trò là không gian trưng bày các sản phẩm, thành tựu và các dự án nổi bật của nhóm.

---

## Giới thiệu (Overview)

- **Nhóm phát triển:** AnomalyWall Team
- **Tác giả / Người tạo:** Enriah
- **Mục đích:** Trưng bày sản phẩm (Products Showcase) và các dự án sáng tạo của nhóm (Team Projects).

## Công nghệ sử dụng (Tech Stack)

- **Frontend Framework:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **3D & Hiệu ứng:** Three.js, Canvas Confetti, Lucide Icons

## Hướng dẫn cài đặt và chạy dự án (Getting Started)

### 1. Cài đặt dependencies
```bash
npm install
```

### 2. Chạy môi trường phát triển (Development)
```bash
npm run dev
```

### 3. Build dự án cho Production
```bash
npm run build
```
